The fastest way to get a Streaming Avatar integration running locally is to start from a template rather than a blank project. Vivix provides a set of pre-built starter applications — one per popular frontend framework — that wire together session creation, TRTC media joining, and the WebSocket control channel for you. The **Vivix Studio CLI** is the tool that lets you browse those templates, scaffold one into a new directory, and start a local development server in a single workflow.

## Available Templates

Vivix maintains starter templates for the most common frontend environments. Each template includes a minimal backend proxy route (so your API key never leaves the server), a ready-to-run TRTC media integration, and an example control-channel client.

## Using Vivix Studio CLI

The Vivix Studio CLI handles everything from picking a template to spinning up your local dev server.

<Steps>
  <Step title="Install the CLI">
    Install the Vivix Studio CLI globally using the install command shown in the [Vivix developer platform](https://platform.vivix.ai). You need Node.js 18 or later. Once installed, confirm the CLI is available:

    ```bash
    vivix --version
    ```
  </Step>
  <Step title="Authenticate with your API key">
    Log in with the API key you generated in the Vivix developer platform. The CLI stores the key in your local config file — it is never sent anywhere other than `api.vivix.ai`.

    ```bash
    vivix login
    ```

    When prompted, paste your API key. You only need to do this once per machine.
  </Step>
  <Step title="Scaffold a template">
    Run `vivix create` to browse the available templates interactively. Select your framework, give the project a name, and the CLI clones the template into a new directory and installs dependencies.

    ```bash
    vivix create my-avatar-app
    ```

    The CLI will prompt you to choose a template:

    ```
    ? Choose a template:
      ❯ Streaming Avatar — React
        Streaming Avatar — Next.js
        Streaming Avatar — Vue
        Streaming Avatar — Vanilla JS
    ```

    After scaffolding, your project directory will look similar to this:

    ```
    my-avatar-app/
    ├── src/
    │   ├── app/
    │   │   ├── api/
    │   │   │   └── sessions/
    │   │   │       └── route.ts        # Server-side session create/close
    │   │   └── page.tsx                # Main avatar UI
    │   ├── components/
    │   │   ├── AvatarStream.tsx        # TRTC video container
    │   │   └── ControlPanel.tsx        # Speak / interrupt controls
    │   └── hooks/
    │       └── useStreamingAvatar.ts   # Session + control channel logic
    ├── .env.local.example              # Copy to .env.local and add your key
    ├── package.json
    └── README.md
    ```
  </Step>
  <Step title="Run locally">
    Copy the example environment file and add your API key, then start the development server.

    ```bash
    cd my-avatar-app
    cp .env.local.example .env.local
    # Open .env.local and set VIVIX_API_KEY=<your key>

    npm run dev
    ```

    Open [http://localhost:3000](http://localhost:3000) in your browser. You should see a live Streaming Avatar session start automatically.
  </Step>
</Steps>
