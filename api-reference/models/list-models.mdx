Use this endpoint to retrieve the list of models your API key is authorized to use. Each model object includes its identifier, product line type, and a human-readable description. Call this endpoint to confirm which models are available before submitting tasks or creating sessions — only enabled models will appear in the response.

## Request

```
GET https://api.vivix.ai/v1/models
```

| Header | Value |
|---|---|
| `Authorization` | `Bearer <API_KEY>` |

There is no request body for this endpoint.

## Example Request

```bash
curl https://api.vivix.ai/v1/models \
  -H "Authorization: Bearer <API_KEY>"
```

## Response

<ResponseField name="models" type="array">
  A list of model objects representing every model enabled for your API key. If a model does not appear here, your key does not currently have access to it.

  <Expandable title="model object fields">
    <ResponseField name="models[].id" type="string">
      The model identifier. Use this value in the `model` field when creating a session or submitting a task — for example, `vivix-a1-stream` or `vivix-w1`.
    </ResponseField>

    <ResponseField name="models[].type" type="string">
      The product line this model belongs to. Either `streaming_avatar` (for use with the Streaming Avatar API) or `video_generation` (for use with the Video Generation API).
    </ResponseField>

    <ResponseField name="models[].description" type="string">
      A human-readable description of the model, including its capabilities and intended use case.
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
  Only models enabled for your API key are returned by this endpoint. If you need access to a model not listed in your response — for example, a higher-tier model or a model in private beta — contact [Vivix support](mailto:support@vivix.ai) to request access.
</Note>
