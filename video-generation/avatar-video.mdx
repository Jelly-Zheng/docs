The Vivix Video Generation API lets you create avatar videos by submitting an asynchronous task and retrieving the result when it's ready. You provide the model, the avatar, the voice, and the content — Vivix handles rendering and returns a playback URL for the finished video. All requests require your API key in the `Authorization` header and must originate from your server, never the browser.

## Submit a Generation Task

Send a `POST` request to `/v1/video-generation/tasks` to queue a new video generation job. The API returns a `task_id` immediately; the video itself is rendered asynchronously.

```bash
curl -X POST https://api.vivix.ai/v1/video-generation/tasks \
  -H "Authorization: Bearer <API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "vivix-a1",
    "text": "Welcome to Vivix. Your AI-powered video is ready.",
    "avatar_id": "avatar_abc123",
    "voice_id": "voice_xyz789"
  }'
```

A successful response returns a `task_id` and an initial status of `pending`:

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "task_id": "task_1a2b3c4d5e",
    "status": "pending"
  }
}
```

Store the `task_id` — you'll use it to poll for the completed video.

## Request Parameters

<ParamField body="model" type="string" required>
  The video generation model to use. Must be one of `vivix-a1-lite`, `vivix-a1`, or `vivix-w1`. Choose `vivix-a1-lite` for faster results, `vivix-a1` for higher visual quality, or `vivix-w1` for world-style generation.
</ParamField>

<ParamField body="text" type="string">
  The script for the avatar to speak. Vivix generates lip sync automatically from this text. Provide either `text` or `audio` (or both, depending on your use case).
</ParamField>

<ParamField body="avatar_id" type="string">
  The identifier of the avatar to use for the video. If omitted, Vivix uses your account's default avatar. You can retrieve available avatar IDs from the Vivix developer platform.
</ParamField>

<ParamField body="voice_id" type="string">
  The identifier of the voice to use for text-to-speech synthesis. If omitted, Vivix uses the default voice associated with the selected avatar. Only relevant when `text` is provided.
</ParamField>

## Poll for Completion

After submitting a task, send `GET` requests to `/v1/video-generation/tasks/{task_id}` to check whether rendering is complete.

```bash
curl https://api.vivix.ai/v1/video-generation/tasks/task_1a2b3c4d5e \
  -H "Authorization: Bearer <API_KEY>"
```

While the video is rendering, the response status will be `processing`:

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "task_id": "task_1a2b3c4d5e",
    "status": "processing"
  }
}
```

When rendering finishes, the status changes to `completed` and the response includes a `video_url`:

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "task_id": "task_1a2b3c4d5e",
    "status": "completed",
    "video_url": "https://cdn.vivix.ai/videos/task_1a2b3c4d5e/output.mp4"
  }
}
```

<Tip>
  Poll every 2–5 seconds to balance responsiveness with request volume. For a reusable polling function with retry limits and failure handling, see the [Task Management](/video-generation/task-management) page.
</Tip>

## Response Fields

<ResponseField name="task_id" type="string">
  The unique identifier for this generation task. Use it in all subsequent polling requests.
</ResponseField>

<ResponseField name="status" type="string">
  The current state of the task. Possible values are `pending` (queued, not yet started), `processing` (actively rendering), `completed` (finished successfully), and `failed` (rendering did not complete).
</ResponseField>

<ResponseField name="video_url" type="string">
  The URL of the finished video, present only when `status` is `completed`. Use this URL to stream or download the generated video. Video URLs may have a limited lifetime — download the file promptly if you need to retain it.
</ResponseField>
